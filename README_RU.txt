UNDERGROUND — инструкция по запуску

1) Установить Python 3.11 или новее.
2) Открыть терминал в папке проекта.
3) Установить зависимости:
   pip install -r requirements.txt
4) Установить токен бота как переменную окружения BOT_TOKEN.
   Linux/macOS:
   export BOT_TOKEN='ВАШ_ТОКЕН'
   Windows PowerShell:
   $env:BOT_TOKEN='ВАШ_ТОКЕН'
5) Запустить:
   python bot.py

Команды в группе:
/newgame — создать набор
/join — присоединиться (также есть кнопка)
/startgame — начать партию
/status — статус партии

Команда /start в личке нужна каждому игроку, чтобы бот мог отправлять роль и ночные действия.

Важно: это первый прототип. Игровые сессии пока хранятся в памяти процесса; SQLite сохраняет только факт запуска личного чата. До постоянного хостинга и публичного запуска нужно добавить устойчивое хранение состояния игры, восстановление таймеров после перезапуска, обработку нескольких групп и проверку всех правил.
